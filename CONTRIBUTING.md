# Contributing to the Wiki

Use this wiki as a living handoff system. Small updates during the season are better than perfect updates after everyone forgets the details.

## How to Edit a Page

1. Open the website.
2. Go to the page you want to update.
3. Click **Edit this page**.
4. Paste a fine-grained GitHub token with **Contents** read/write access.
5. Load the page, make your changes, preview them, and save.

You can also edit pages directly in GitHub if you prefer GitHub's built-in editor.

## What to Document

- Process steps.
- Decisions and why they were made.
- Links to CAD, code, spreadsheets, photos, videos, and test data.
- Problems, failures, and fixes.
- Advice for next year's team.

## Good Commit Messages

- `Update mechanical lead handoff`
- `Add drivetrain testing notes`
- `Document sponsorship process`
- `Add competition packing checklist`

## Review Expectations

Use pull requests for major structural changes, rules interpretations, official reports, or anything that affects multiple teams.
