Token Setup

Each editor needs GitHub access to the repo and a fine-grained personal access token. The token is kept in this browser session only.

  1. Open GitHub account settings.
  2. Create a fine-grained token for this repository.
  3. Grant Contents read and write access.
  4. Paste it here when editing.

Team Rules
