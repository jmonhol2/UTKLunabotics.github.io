# Roles and Ownership

Use this page to help future members understand who owns each part of the project and what knowledge each role should hand off.

Update the table to match the team's real structure.

## Ownership Rule

Every major subsystem, process, and recurring responsibility should have:

- A current owner.
- A backup owner.
- A handoff page.
- A team or subteam page, if the work belongs to a functional group.
- Links to source files.
- A list of known problems and next steps.
