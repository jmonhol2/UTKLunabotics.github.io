# Subsystems

Create one page per robot subsystem. Each page should explain the design, the reasoning behind it, how it was built, how it was tested, and what future teams should know.

Suggested subsystem pages:

- `chassis.md`
- `excavation.md`
- `conveyance.md`
- `deposition.md`
- `electrical.md`
- `software.md`
- `autonomy.md`
- `controls.md`
- `sensors.md`

Use the [Subsystem Page Template](../../templates/subsystem-page.md).
