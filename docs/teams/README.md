# Teams and Subteams

This section documents each major team and the subteams inside it. Use it to capture how work moves through the organization, not just what the robot looks like at the end.

Suggested main teams:

- [Mechanical Team](mechanical/README.md)
- [Electrical Team](electrical/README.md)
- [Software Team](software/README.md)
- [Business and Outreach Team](business-outreach/README.md)
- [Operations Team](operations/README.md)

Use the [Team Page Template](../../templates/team-page.md) for main team pages and the [Subteam Page Template](../../templates/subteam-page.md) for subteam pages.

## Suggested Structure

Each main team should include:

- Team overview.
- Leadership and members.
- Subteams.
- Responsibilities throughout the project cycle.
- Tools, files, and accounts.
- How this team coordinates with other teams.
- Lessons learned.

Each subteam should include:

- Scope of work.
- Owner.
- Inputs needed from other teams.
- Outputs delivered to other teams.
- Process notes.
- Known issues.
- Next-year advice.
